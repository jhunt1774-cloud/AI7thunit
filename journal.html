Portfolio planner

1 requirement · 2 my algorithm/code · 3 before/after · 4 three tests · 5 decision/tradeoff · 6 credits/limitation. Include a source label for every result. A simulated result must never be renamed an actual Blender observation.

Vocabulary

Algorithm: ordered method. Decomposition: divide a problem into workable parts. Abstraction: retain relevant detail. Variable: named value. Parameter: named procedure input. Argument: value supplied in a call. Loop: repeat instructions. Conditional: choose an action. Regression test: check earlier behavior after a change. Inference: use a trained model. MCP: a protocol allowing an application to use exposed tools.
