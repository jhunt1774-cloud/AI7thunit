The ideas we need today

  • Training and inference are different processes: Training changes a model through examples and a learning process.
  • Compare groups before making a claim: A test result is correct answers divided by tested examples.
  • Calculate a percentage step by step: Accuracy percent=(correct/total)×100.

The full explanations and code card are on today’s student lesson page.

The rules we will use and check

  • Use more than color for a sign: A non-color cue communicates through words,shapes,arrows,patterns,or another usable channel.
  • Unsupervised learning looks for patterns without supplied labels: A label is a supplied category,such as “bridge sign” or “gate sign.” Unsupervised pattern finding groups records using similarities when those category labels are not supplied.
  • Toy data and inclusive evaluation have limits: Our sign numbers are invented examples for reasoning.
