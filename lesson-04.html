First:read today’s explanation

An algorithm is an ordered method for completing a task. Two algorithms may both produce eight bridge planks but use different representations. Algorithm A writes eight separate create instructions. Algorithm B repeats one instruction eight times while changing x. Repetition can make a procedure easier to revise. It does not automatically mean Blender will create fewer objects or render faster.

Our river corridor runs north–south from x=-2 to x=2. The bridge crosses east–west at y=-4. Eight touching planks are centered at x=-3.5,-2.5,-1.5,-0.5,0.5,1.5,2.5,3.5. Each plank is 1 unit long in x, 3 units wide in y, and 0.4 units high, centered at z=0.2. The bridge extends from x=-4 to x=4, leaving 2 units of bank coverage on each side of the river.

Before calling one algorithm efficient, name your measure. Source lines, human edits, tool calls, object count, and elapsed seconds are different measures. We will count explicit instruction lines and the edits needed when a request changes from eight to ten planks. We will not invent timing data. An off-by-one error happens when a process repeats once too often or too few times. A trace table lets us inspect every position before using a tool.

Code card you will read or change

# Pseudocode: CREATE_PLANK is our named modeling operation.
n = 8
x = -(n - 1) / 2
REPEAT n TIMES:
    CREATE_PLANK(center=(x, -4, 0.2), dimensions=(1, 3, 0.4))
    x = x + 1

Repair the missing last plank

Choice A · suggested 10–18 minutes; move on when evidence is complete

Bridge design contest

Compare eight 1-unit planks with four 2-unit planks, both spanning -4 to 4. Write coordinates and dimensions for both. Check coverage, object count, and total plank length. Recommend a design for lower object count; explain a tradeoff in decorative detail and why timing is still unknown.

Turn in: Two specification tables and a four-criterion argument.

Choice B · suggested 10–18 minutes; move on when evidence is complete

Route verification

On the base map, mark a route from the tower (-7,4) to the bridge entrance (-4,-4), then across to (4,-4), then to the future homes near (7,3). Write an ordered waypoint algorithm. A partner follows it without shortcuts. Record two ambiguities and revise; check whether any crossing happens away from the bridge.

Turn in: Route map, waypoint list, partner audit, revised crossing test.

Further challenge

Odd and even bridges

Trace n=1, n=5, and n=10 using start x=-(n-1)/2. State the total span and prove the set stays centered at x=0 for both odd and even n.

Turn in: Your supported explanation,trace,or revised plan.

If technology fails

Draw the river strip and place eight paper plank rectangles using the trace. Save the algorithm in the class ledger for later execution. Students compare planned geometry, without claiming an actual timing result.
