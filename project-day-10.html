The ideas we need today

  • Editable project versus viewing image: A .blend file is Blender’s editable project/scene format.
  • Separate storage from a release: An archive keeps project files for future work;a release is the selected material shared with an audience.

The rules we will use and check

  • A failed render does not erase the work: A render is a produced image of a scene.
  • Credit actual contributions: Credits acknowledge human design,writing,testing,and artwork,plus any used external resources and an honest description of AI assistance.
  • Defensible claims include limits: A claim is defensible when its evidence supports its scope.
